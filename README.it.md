# LECTOR

[English](README.md) · [Română](README.ro.md) · [Français](README.fr.md) · **Italiano** · [Español](README.es.md) · [Português](README.pt.md) · [Deutsch](README.de.md) · [Magyar](README.hu.md)

Libri letti ad alta voce — con le voci locali del tuo dispositivo, senza account. Un solo file HTML, funziona offline.

**[Apri l’app →](https://lector.chiuta.ro/)**

_Versione: 14.1.2 · Ultimo aggiornamento: 2026-11-17_

## Funzioni

- EPUB, DOCX, PDF (pdf.js; PDF scansionati tramite OCR), TXT, HTML o testo incollato.
- Voci del dispositivo con evidenziazione della parola letta, timer di spegnimento, velocità e tono, modalità solo ascolto; voce neurale Piper sperimentale.
- Capitoli, ricerca, segnalibri, dizionario di pronuncia e libreria nel browser con backup e importazione.
- Temi (scuro, seppia, alto contrasto), font per la dislessia e interfaccia in 8 lingue.

## Utilizzo

Apri la pagina online, oppure scarica `index.html` e aprilo in un browser recente. Nessuna installazione, nessuna build.

## Limiti

- Sul telefono la voce di sistema si ferma quando lo schermo si blocca (limite del browser).
- La qualità della voce dipende dalle voci installate; senza una voce ro-RO, il testo rumeno suona male. Gli archivi EPUB/DOCX sono limitati a 150 MB dopo la decompressione.

## Privacy

Tutto resta nel tuo browser (localStorage / IndexedDB); nessun account, nessun tracciamento. Rete solo su richiesta: pdf.js, OCR e voce neurale Piper.
