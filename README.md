# LECTOR

**English** · [Română](README.ro.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Español](README.es.md) · [Português](README.pt.md) · [Deutsch](README.de.md) · [Magyar](README.hu.md)

Books read aloud — with your device’s local voices, no account. One HTML file, works offline.

**[Open the app →](https://lector.chiuta.ro/)**

_Version: 14.1.3 · Last updated: 2026-11-20_

## Features

- EPUB, DOCX, PDF (pdf.js; scanned PDFs through OCR), TXT, HTML or pasted text.
- Device voices with highlighting of the word being read, sleep timer, speed and pitch, listen-only mode; experimental neural Piper voice.
- Chapters, search, bookmarks, pronunciation dictionary, and a library in the browser with backup and import.
- Themes (dark, sepia, high contrast), dyslexia font and an interface in 8 languages.

## Usage

Open the page online, or download `index.html` and open it in a recent browser. No installation, no build.

## Limits

- On phones the system voice stops when the screen locks (a browser limit).
- Voice quality depends on the voices installed; without a ro-RO voice, Romanian text sounds wrong. EPUB/DOCX archives are limited to 150 MB after decompression.

## Privacy

Everything stays in your browser (localStorage / IndexedDB); no account, no tracking. Network only on request: pdf.js, OCR and the neural Piper voice.
